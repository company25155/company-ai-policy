# company-ai-policy

Avail（アベイル）の、社内でAIを使うための共通のルールです。

## 3つの層

| 層 | ファイル | 対象 |
|---|---|---|
| 第1層：社内AI利用ルール | `policy/ai-usage-rules.md` | 業務でAIを使う全社員 |
| 業務別ルール | `policy/business/` | その業務の担当者（例：EC・広報） |
| 第2層：システム開発のAI作業規程 | `harness/ai-work-rules.md` | システム担当がAIに作業させるとき（全リポジトリ共通） |
| 第3層：各リポジトリの補足 | 各リポジトリのAI向けの指示ファイル | そのリポジトリ |

- 上の層が常に優先します。下の層は、決まりを厳しくすることはできても、緩めることはできません。
- 社員向けの「AIの設定文」は `policy/ai-settings-text.md` です。サービスごとの設定の手順は、社内ポータルで案内します。

## 各リポジトリへの取り込み

- 第1層と第2層は、各リポジトリの `.ai-rules/` に自動で取り込まれ、PRとして届きます。
- 取り込み先の `.ai-rules/` は書き換えないでください。書き換えると、自動の検査で止まります。
- 各リポジトリのAI向けの指示ファイルの先頭で、`.ai-rules/` のファイルを読み込みます。

## 変更のしかた

- 変更はPRで行います。`policy/` と `harness/` の変更は、責任者の承認がないと取り込めない設定にしています。
- 改正したら、版の番号を上げ、`CHANGELOG.md` に書き、社内ポータルなどでお知らせします。

## このリポジトリに置かないもの

このリポジトリは公開しています。次のものは、非公開の記録用リポジトリに置きます。

- 使っている具体的なサービス・ツールの名前（GitHub を除く）と、サービスごとの決まり（第2層の別表）
- 承認済みの外部連携の一覧、承認・事故の記録、利用者ごとの設定の記録
- 人の名前、社内システムの内部の情報、鍵・個人情報
